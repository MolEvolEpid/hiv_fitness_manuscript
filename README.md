# Code and data related to the manuscript "The interplay between convergent and divergent selective pressures shapes within-host HIV-1 evolution"

- `hiv_fitness_figures.qmd`: code to recreate all figures and summary statistics in the manuscript.
- `hiv_fitness_figures.html`: rendered html file of the figures
- `hiv_fitness_figures_files`: directory containing manuscript figures in png format
- `scripts`: directory containing scripts used to perform analyses
- `data/metadata`: metadata related to the empirical sequences
- `data/empirical_alns_trs`: directory containing empirical alignments and phylogenies
- `data/summaries`: directory containing summary files of the analyses (used to generate the manuscript figures)
